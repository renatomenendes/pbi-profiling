# pbi-profiling v1.0.0

First production release of `pbi-profiling`.

## What it does

`pbi-profiling` converts a Power BI PBIP project's technical structure into a navigable runbook and machine-readable profiling artifacts.

It analyzes:

- TMDL semantic models;
- PBIR reports;
- DAX;
- Power Query/M;
- sources and relationships;
- pages, visuals and bookmarks;
- usage and structural importance;
- complexity, health and maintenance risk;
- analytical opportunities.

## Outputs

- `profile.html`
- `profile.json`
- `profile.rag.jsonl`

## Distribution

Download:

- `pbi-profiling-v1.0.0-windows-portable.zip`
- `SHA256SUMS.txt`

Verify the SHA-256 checksum before extraction.

## Requirements

- Windows 10 or 11.
- Node.js 20 or newer.
- Power BI Desktop only for the optional PBIX-open workflow.

No administrator rights, `npm install`, Python installation or PowerShell ExecutionPolicy change is required.

## PBIX and PBIP

PBIP is the profiling contract.

For PBIX:

1. open the file from `pbi-profiling`;
2. save it in Power BI Desktop as **Power BI Project (.pbip)**;
3. select the saved PBIP folder;
4. validate and generate the runbook.

Programmatic PBIX-to-PBIP conversion is intentionally not part of the production path.

## Security and privacy

- local loopback server only;
- token-protected session API;
- read-only PBIP analysis;
- self-contained generated HTML;
- no external CDN;
- no corporate artifacts included in the public release.

See `SECURITY.md` for the security policy and `ATTRIBUTIONS.md` / `THIRD_PARTY_NOTICES.md` for provenance.
